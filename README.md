# Mental-Health
# Mental Health Support Platform

A web application designed to support mental well-being through mood tracking, mental health resources, and peer support.

## Features

* User authentication
* Mood tracking
* Mental health resources
* Peer support
* User dashboard

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Supabase

## Installation

1. Clone the repository:
   `git clone https://github.com/bhagyashri8711/Mental-Health.git`
2. Navigate to the frontend folder: `cd frontend`
3. Install dependencies: `npm install`
4. Configure your Supabase environment variables.
5. Start the app: `npm run dev`
